Agent #001

It can spend money. It cannot spend outside its authority — not if it is confused, not if it is jailbroken, not if someone takes its key. The limits are in the script that unlocks the coin, so the only party whose opinion matters has already been consulted by the time a transaction exists.

The payee count is the length of the allowlist, not a headline. A grant commits to its payees at genesis and cannot add one afterwards — so “authorized payees: 1” means there is exactly one address in the universe this agent can pay. That number grows when a new grant is issued, never when the agent decides it would like to buy something else.

Published

What it does

Agent #001 reads the Kaspa network on a schedule and publishes the difference between two readings. It never asks the chain what happened yesterday — it asks where the chain is now, writes that down, and yesterday’s answer is the file it wrote yesterday. No indexer, no archive node, no history. 

—

Every figure there is the difference between two counters the network keeps for its own reasons. Nothing is sampled or extrapolated; the hashrate is the node’s own estimate and says so. Both readings are kept, so anyone with a node can take their own pair and get the same differences.
